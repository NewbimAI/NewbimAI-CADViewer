# 测量（`measure` + 界面测量工具）

分两层，**不要混着用**：

| 要量的东西 | 用什么 | 精度/口径 |
|---|---|---|
| 已知图纸坐标之间的距离/折线长度/面积/夹角 | `cad.mjs measure` | 纯算式，与坐标同精度 |
| 贴在图元上的量（墙厚、洞宽、净面积、半径、端点坐标） | 界面底部工具条 | 引擎按图元几何 + 吸附点量，和看图同源 |

## 1. 命令行（坐标测量）

单位是**图纸单位**（`$INSUNITS=4` 时是毫米）。坐标来源：`readout` 的文字/图块位置、`summary.extents`、用户给的图纸坐标。
**不要**拿屏幕像素或截图比例换算——那与图纸坐标不是线性关系。

```bash
# 两点距离（另给 Δx/Δy/方位角）
node <skill>/scripts/cad.mjs measure distance --points "0,0;3000,4000"
# 折线长度（逐段 + 总长）
node <skill>/scripts/cad.mjs measure length --points "0,0;1000,0;1000,500"
# 闭合面积 + 周长（点的顺序任意，输出带符号面积与朝向）
node <skill>/scripts/cad.mjs measure area --points "0,0;4000,0;4000,3000;0,3000"
# a → 顶点 → c 的夹角（0..180），另给两条边的方位角与长度
node <skill>/scripts/cad.mjs measure angle --points "1000,0;0,0;0,1000"
```

输出字段：

| 子命令 | 字段 |
|---|---|
| `distance` | `distance`、`dx`、`dy`、`azimuthDeg`（0°=+X，逆时针为正） |
| `length` | `segments[]`（逐段 `dx/dy/length`）、`total` |
| `area` | `area`（绝对值）、`signedArea`、`perimeter`、`orientation`（`ccw`/`cw`）、`closed` |
| `angle` | `angleDeg`、`azimuthADeg`、`azimuthCDeg`、`legA`、`legC` |

`--points` 接受 `;`、中文分号、换行分隔的点，点内用 `,` 或空格分隔 x/y。

## 2. 界面测量工具（贴合图元）

打开界面（`serve` 或 `open`）后，**底部胶囊式停靠工具条**：左侧测量、右侧视图，中间细分隔线。
测量 6 种，图标按钮带 `title` 提示：

| 工具 | 怎么用 | 回答什么 |
|---|---|---|
| 距离 | 点两个吸附点 | 两点净距/水平/垂直分量 |
| 连续长度 | 依次点多个点，双点结束 | 沿路径长度（管线、轮廓周长） |
| 面积 | 沿闭合轮廓依次点 | 面积 + 周长（房间净面积、地块） |
| 角度 | 点两条边（或三点） | 夹角/开门方向 |
| 半径 | 点圆弧/圆 | 半径、直径 |
| 坐标 | 点一个点 | 该点图纸坐标 |

吸附：端点、中点、圆心、象限点、交点、线上最近点。缩放时数值与标注不漂移（数值按图纸单位算，不按屏幕像素）。
`Esc` 或再点一次同一按钮退出测量。

agent 用内置浏览器操作时：先 `serve`，等左下状态条 `data-dxf-status` 变成 `done`，再点工具条按钮、按提示顺序点画布；
**测量数值以工具条/标注上的读数为准**，不要自己用截图里的像素比例反算。

## 3. 常见问答口径

- “这面墙多厚？”→ 界面「距离」量两面墙线；不要用 `measure` 猜，除非用户直接给了两条墙线的坐标。
- “这个房间多少平？”→ 界面「面积」沿净轮廓点一圈；报告里注明是**净面积**还是**轴线面积**。
- “这段管多长？”→ 界面「连续长度」；只给坐标时用 `measure length`。
- 图纸单位不明（`$INSUNITS=0`）时，先声明“按图纸单位”，不要自动当成毫米。
